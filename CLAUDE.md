# Regras do repositório — Distribuidora Pantanal

Estas regras valem para todo trabalho feito neste repositório, sempre.

## Empresa
- Todo o trabalho é para a **Distribuidora Pantanal**.

## Idioma
- Escreva tudo em **português do Brasil**: textos, interfaces, comentários, mensagens de commit, títulos e descrições de pull request, resumos e respostas.

## Formatos
- **Valores em reais:** `R$ 1.234,56` (ponto como separador de milhar, vírgula nos centavos, sempre duas casas decimais).
- **Datas:** `dd/mm/aaaa` (exemplo: 18/11/2026).

## Identidade visual
- **Cores:** azul escuro `#14213D` e amarelo `#F5C518`.
- **Logo:** `dados/logo_pantanal.png`.

## Interface
- Simples e clara, pensada para quem **não é da área de tecnologia**.
- Evite termos técnicos; use linguagem do dia a dia e instruções diretas.

## Organização
- Cada projeto fica na **sua própria pasta** na raiz do repositório (por exemplo, `despesas/`, `orcamento/`).
- Dados compartilhados ficam em `dados/`.

## Forma de trabalhar
- **Antes de mudanças grandes**, apresente um plano e espere a aprovação.
- **Ao terminar**, abra um pull request com um resumo em português do que mudou.
